# Signage Player

Киоск-плеер: видео с сервера по кругу на весь экран, расписание вкл/выкл, автозапуск.

## Новое
- Тёмный интерфейс настройки.
- Любой из 4 углов экрана: Логотип / Погода / Часы / Пусто.
- Логотип: из галереи (скрытое меню) или с сервера (поле logoUrl в /apis/config).
- Погода: Open-Meteo (без ключа), город задаётся в меню, обновление каждые 15 мин.
- Скрытое меню: 5 нажатий в центре экрана за 4 секунды -> PIN (по умолчанию 1234).
  В меню: сервер, углы, логотип и его размер, город, звук, ручной чёрный экран,
  смена PIN, синхронизация, выход из приложения.

Сборка: Android Studio -> Open -> Sync -> Run.
